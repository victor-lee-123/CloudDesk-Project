# CloudDesk: A Cloud-Based Help Desk and Ticket Management Web Application

Project Overview

This project proposes the development of CloudDesk, a cloud-based web application that allows users to submit support tickets, track ticket progress, and receive responses through an online system. The platform is designed to simulate a modern help desk service that can be accessed anytime over the Internet. In addition, administrators will be able to manage tickets, update statuses, and respond to user requests through an admin dashboard.

The project is developed as a containerized web application and deployed on AWS cloud infrastructure. By using Docker and AWS services, the system demonstrates key cloud computing concepts such as service deployment, scalability, reliability, and security.
